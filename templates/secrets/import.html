Up to {{ max_rows }} secrets and {{ max_kb }} KB. A file ending .csv is read as CSV; anything else as .env.

  • .env: one NAME=value per line. Values can be in quotes, and lines starting with # are skipped.
  • CSV: a first line naming the columns name,value, and optionally content_type, expires (YYYY-MM-DD), tags (env=prod;team=ops), description (a note of up to 256 characters, kept in the description tag), owner (one email address) and notify (up to {{ crate::owner::MAX_NOTIFY }} addresses separated by commas, in double quotes).{% if shell.require_owner %} Keyring is set to need an owner, so a row without one isn't imported.{% endif %}

Names are changed to fit Key Vault: anything but letters, numbers and hyphens becomes a hyphen, so DB_PASSWORD becomes DB-PASSWORD.
