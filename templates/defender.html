{% call ui::about() %}

Defender for Key Vault is a plan in Microsoft Defender for Cloud. When it's on for a subscription, it raises an alert when a vault is used in an unusual way: secrets listed and read in bulk, access from a suspicious address or from Tor, or an unusual access policy change.

Keyring reads the alerts and each subscription's plan from Azure Resource Graph, as you. You see the alerts for the subscriptions where you have Security Reader or Reader. Keyring doesn't change alerts: dismiss or resolve them in Defender for Cloud.

Alert titles and entities come from whoever set the alert off, so they're shown as plain text.
